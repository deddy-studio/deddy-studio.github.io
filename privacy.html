Privacy Policy

Last updated: 10 November 2026

Deddy Studio Tools is a private set of tools used only by its owner to manage the owner's own YouTube channels.

What data the tools access

With the owner's permission through Google sign-in, the tools use the YouTube Data API to upload videos, set thumbnails, edit video details, and schedule publish times on the owner's channels. They read basic channel information to confirm the right channel is selected.

How the data is stored

The sign-in token is stored only on the owner's private server. Video files and details stay on that server and on YouTube.

Sharing

No data is sold, shared with third parties, or used for advertising. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at https://myaccount.google.com/permissions.
